## アクセス解析

このサイトでは、アクセス解析に Google Analytics（GA4）を使っている。GA4 は Cookie を使って、閲覧されたページや利用ブラウザ、地域などの情報を収集する。個人を特定する目的では使っていない。収集された情報の扱いは [Google のプライバシーポリシー](https://policies.google.com/privacy) に従う。Cookie はブラウザの設定で無効にできる。

## 配信と画像のホスティング

このサイトは Cloudflare Pages で公開していて、記事の画像は Cloudflare R2 から images.aoiro-labo.com 経由で配信している。アクセスの記録は Cloudflare 側に残る場合がある。

## コメント

記事へのコメントには giscus を使っている。giscus は GitHub Discussions を利用した仕組みで、投稿には GitHub アカウントが必要になる。コメントの内容は GitHub 上に公開され、その扱いは GitHub のポリシーに従う。

## 埋め込みコンテンツ

記事には X の投稿の埋め込みや、YouTube のサムネイル画像などを表示することがある。これらを表示する際に、各サービス（X、Google など）のサーバーからスクリプトや画像を読み込むため、各サービスのプライバシーポリシーが適用される。

## アフィリエイトについて

記事内でアフィリエイトリンクを使う場合は、その記事の中に明示する。明示のないリンクはアフィリエイトではない。

## 免責
