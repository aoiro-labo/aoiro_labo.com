このページでは、aoiro-labo（以下「このサイト」）における、閲覧者に関する情報の扱いについて定める。このサイトは個人が運営しているブログで、運営者は aoiro。

## 取得する情報と利用目的

このサイトを閲覧すると、配信とアクセス解析の仕組み上、次の情報が自動で取得される。

- IPアドレス、ブラウザや端末の種類（User-Agent）、閲覧したページ、参照元（リファラー）、アクセス日時

これらはサイトの配信、障害や不正アクセスへの対応、アクセス傾向の把握のために使う。個人を特定する目的では使っていない。

コメントを投稿した場合は、後述の giscus の仕組みを通じて GitHub 側に情報が渡る。メールで問い合わせた場合は、送られた本文とメールアドレスを返信と対応のために保管する。

## Cookie について

後述の Google Analytics が、閲覧の計測のために Cookie を使う。このサイト自体は、ログイン機能などを持つわけではなく、計測以外の目的で Cookie を発行していない。Cookie はブラウザの設定で無効にでき、無効にしても記事の閲覧に支障はない。

## アクセス解析

アクセス解析には Google Analytics（GA4）を使っている。GA4 は Cookie を使って閲覧されたページや利用ブラウザ、地域などの情報を収集し、その扱いは [Google のプライバシーポリシー](https://policies.google.com/privacy) に従う。収集を止めたい場合は、ブラウザの設定で Cookie を無効にするか、[Google アナリティクス オプトアウト アドオン](https://tools.google.com/dlpage/gaoptout) を使える。

## 配信と画像のホスティング

このサイトは Cloudflare Pages で公開していて、記事の画像は Cloudflare R2 から images.aoiro-labo.com 経由で配信している。アクセスの記録は、配信とセキュリティのために Cloudflare 側に残る場合がある。その扱いは [Cloudflare のプライバシーポリシー](https://www.cloudflare.com/privacypolicy/) に従う。

## コメント

記事へのコメントには giscus を使っている。giscus は GitHub Discussions を利用した仕組みで、投稿には GitHub アカウントが必要になる。コメントの内容と、投稿に使った GitHub アカウントの情報は GitHub 上に公開され、その扱いは [GitHub のプライバシーに関する声明](https://docs.github.com/ja/site-policy/privacy-policies/github-general-privacy-statement) に従う。コメントを削除したい場合は、GitHub 上で自分で削除するか、後述の問い合わせ先まで連絡してほしい。

## 埋め込みコンテンツと外部リソース

記事には X の投稿の埋め込みや、YouTube のサムネイル画像などを表示することがある。また、このサイトについて（About）のページでは、外部サイトの favicon を読み込んでいる。これらを表示する際に、各サービス（X、Google、GitHub など）のサーバーからスクリプトや画像を読み込むため、読み込み先のサービスのプライバシーポリシーが適用される。

## 広告とアフィリエイトについて

このサイトには、現在、広告を掲載していない。記事内でアフィリエイトリンクを使う場合は、その記事の中に明示する。明示のないリンクはアフィリエイトではない。

## 第三者への提供

取得した情報を、本人の同意なく第三者に提供することはない。ただし、法令に基づく開示請求があった場合や、不正アクセスへの対応など正当な理由がある場合はこの限りではない。なお、アクセス解析や配信、コメントに使っている外部サービス（Google、Cloudflare、GitHub）へは、各サービスの仕組み上、情報が送信される。

## 情報の開示・訂正・削除

自分に関する情報の開示、訂正、削除を求める場合は、後述の問い合わせ先まで連絡してほしい。このサイト側で保管している情報（問い合わせメールなど）については対応するが、外部サービス側に保管されている情報については、各サービスでの手続きが必要になる場合がある。
